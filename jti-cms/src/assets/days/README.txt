DAY-BY-DAY PHOTOS
=================
One optional photo per day of each itinerary. Filenames follow this pattern:

    <itinerary-slug>-day-01.jpg, -day-02.jpg, ...

e.g.  best-of-assam-day-01.jpg    tea-tour-day-05.jpg

Numbers follow the order the days appear on the page (Day 1 = 01). Where a page
groups days (e.g. "Days 4-7"), that whole block counts as ONE slot.

If a file isn't here, that day simply shows no image - the page stays clean.
Recommended: JPG, ~1600px wide, landscape, under ~300KB.
See IMAGE-INDEX.md in the main folder for the exact count per itinerary.
