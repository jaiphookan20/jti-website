JTI WEBSITE — PHOTO FOLDER
==========================
Drop your own photos here to replace any image on the site.
Every image has its own filename. If a file isn't here, the site shows the
current stand-in automatically, so nothing ever looks broken.

WHERE THINGS GO
  site/assets/        page images   (heroes, cards, galleries, section images)
  site/assets/days/   day-by-day itinerary photos

FINDING A FILENAME
  Easiest: open the site in a browser, right-click the image ->
  "Open image in new tab" - the filename is at the end of the address bar.
  Full list: see IMAGE-INDEX.md in the main folder.

NAMING
  home-01.jpg, home-02.jpg ...        homepage (01 = first image / hero)
  tours-01.jpg ...                    Journeys listing page
  itin-<tour>-01.jpg ...              an itinerary page
  park-<park>-01.jpg ...              a park guide
  story-<story>-01.jpg / ourstory-01.jpg / journal-01.jpg
  days/<tour>-day-01.jpg ...          day-by-day photos

SIZES
  Page images: JPG, ~2000px wide, under ~400KB
  Day photos : JPG, landscape, ~1600px wide, under ~300KB
  Free tools : squoosh.app  or  Mac Preview > Tools > Adjust Size
